# Data gaps

- No permission-cleared, time-synchronized field dataset with surface load and position, independently measured downhole force and position, and matching rod geometry was obtained.
- No operational data with confirmed event times, healthy monitoring duration, equipment interventions and verified root causes was available. Synthetic scenario truth supports simulator tests and model experiments.
- The public controller exports omit a sample-level time vector. Their pressure, tubing and rod geometry inputs are unavailable. The downhole columns cannot establish downhole ground truth.
- The Sandia report describes pressure, temperature, load and acceleration across five tool locations. A reusable numerical archive for that campaign was not located. [UNT archive](https://digital.library.unt.edu/ark:/67531/metadc677984/).
- QRod has publicly described predictive inputs and outputs. A reproducible, licensed matching case file was unavailable. libzrod access requires authorized credentials. [QRod](https://www.echometer.com/software/qrod) · [libzrod](https://pypi.org/project/libzrod/).
