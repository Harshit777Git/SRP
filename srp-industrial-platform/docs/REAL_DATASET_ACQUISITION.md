### Reproduce permitted demonstration downloads

Run from the repository. Retain the original archives locally. The audit reports archive hashes, ASCII card geometry and nested container member types.

```powershell
New-Item -ItemType Directory -Force state/vendor
curl.exe -fLsS 'https://drive.google.com/uc?export=download&id=1TPu0JoDc0fr0Ygx6WKWPOL4HHhk_GJ5B' -o state/vendor/echometer-session09.zip
curl.exe -fLsS 'https://drive.google.com/uc?export=download&id=1Nzp6DK76Gbnt6GYKAQSl6UsyhF4aHinV' -o state/vendor/echometer-session20.zip
python scripts/audit_real_datasets.py
```

Public controller URL inventory for an authorized downloader. After obtaining reuse permission, either link can be downloaded with `curl.exe -fLsS '<listed URL>' -o '<approved local filename>'`.
