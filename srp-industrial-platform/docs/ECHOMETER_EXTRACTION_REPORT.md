# Echometer Phase 3 extraction

The read-only inventory records 84 TWM example files (39 `.bwf`, 45 numbered native records), 68 TAM native DYN test files, and 2 standalone ASCII DYN traces: 154 file entries in `data/engineering_reference/echometer_manifest.json`. The two ASCII traces contain 132 and 216 ordered surface load/displacement pairs in inches and lbf and are copied under `data/engineering_reference/echometer/`. They are demonstration examples of unverified measurement origin and **benchmark-only** use; no fault labels were assigned. Ten QRod `.qrd` design files were also found in the user archive and Session 20 ZIP. They are inventoried separately in the QRod results workbook, not counted as numerical predictions.

The TWM operating-conditions dialog requires the operator's own acceptance. It was not accepted here. No protected native format was decoded or decrypted, and no provider export was produced. The exact authorized next action is for the user or their authorized employer representative to review and, if appropriate, accept the displayed TWM terms, then use the application's normal export controls. The original TWM, TAM and QRod files were not changed.

The [TWM quick reference](https://www.echometer.com/Portals/0/Quick%20Reference%20Guides/TWM%20Quick%20Ref.pdf) documents `File → Data Export` for a multi-data spreadsheet, with selected dates, groups, data sets, modules and output path. It separately documents graphical copying, which is not a numerical card export. The [QRod guide](https://www.echometer.com/Portals/0/Quick%20Reference%20Guides/QRod%20Help%20and%20User%20Guide.pdf) documents saved designs and a print report of inputs/results/graphs; it does not in the inspected text establish a machine-readable predicted-card export. [Echometer's QRod page](https://www.echometer.com/software/qrod) describes importing measured surface DYN cards over predicted plots; that does not make the imported card a QRod prediction. TAM release notes mention a DYN data export for PIP, but no accessible supported export was completed in this environment.

The OneDrive ZIP hash and safe nested-archive audit remain in `data/evaluation/onedrive_zip_inventory.json`; `reports/SRP_IMPORT_VALIDATION.md` describes its 125 inner entries. Only the two verified ASCII traces are counted as numerical Echometer cards. Native record counts are files, not independent strokes.
