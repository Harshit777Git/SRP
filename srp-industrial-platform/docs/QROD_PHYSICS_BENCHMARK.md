# QRod physics benchmark

**Independent benchmark status: FAIL — NO NUMERICAL COMPARISON.** Ten QRod `.qrd` designs were inventoried. Their complete input configurations and predicted numerical curves were not exported through a supported interface. The two accessible ASCII DYN traces are demonstration surface cards, not proven QRod predictions or equivalent matched wells. No load RMSE, card-area difference, torque error or QRod agreement percentage can honestly be calculated.

`data/evaluation/qrod_benchmark_results.json` and the Phase 3 workbook classify each design `REFERENCE_EXPORT_UNAVAILABLE`. The 30-well forward/inverse comparisons in Phase 3 are synthetic self-consistency results and must not be substituted for this independent benchmark.

To proceed, an authorized user must open each QRod design in the normal application, export or print complete input parameters and numerical prediction curves if the installed version supports them, and record units and output provenance. A QRod screenshot alone permits only visual comparison. Equivalent simulator configurations must then be checked before quantitative metrics are calculated.
